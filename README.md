# Генератор стартовых писем Макситет

Онлайн-сервис формирует готовое письмо преподавателю по данным распределения нагрузки, силлабусов и базы студенческих групп.

Семестр начинается 2 сентября 2026 года, первая неделя — нечётная. Ссылки в письме сохраняются кликабельными при копировании в почту.

Сайт публикуется автоматически через GitHub Pages.
